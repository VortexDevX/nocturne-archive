# Nocturne brand assets

The crescent embraces an open book: a quiet place to read after dark. The sage emblem pairs with the archive's warm paper, charcoal green surfaces, and serif headings.

- Transparent master: `public/brand/nocturne-mark.png`
- Small UI mark: `public/brand/nocturne-mark-64.png`
- App icons: `public/brand/nocturne-icon-{48,180,192,512}.png`
- Sage: `#9bbda6`; charcoal: `#171c1a`; paper: `#f7f4ed`.

Generated with the built-in imagegen tool. App sizes are downscaled exports; maskable icons include charcoal padding. New assets use dedicated filenames.

## Generation prompt

Use case: logo-brand. Asset type: production brand symbol and app icon for Nocturne, a refined personal novel reading sanctuary. Create one original, exceptionally simple editorial publishing emblem: a crescent moon that curves gently around an open book, the two shapes fused into a single memorable balanced mark. Quiet, literary, botanical, timeless. Flat vector-like silhouette with crisp generous shapes, substantial stroke weight so it reads clearly at 24px. Muted sage green #9bbda6 as the sole solid mark color. Centered on genuinely transparent background, square composition, symbol fills approximately 75 percent of the canvas, comfortable clear space around all edges. No words, no letters, no wordmark, no gradients, no shadows, no 3D, no sparkle clusters, no border, no background texture. The existing app pairs warm ivory #f7f4ed, charcoal green #171c1a, sage, and Georgia serif typography. Deliver a clean transparent PNG emblem, not a mockup.

## Final refinement prompt

Refine this logo into a polished final app emblem for Nocturne. Preserve the crescent moon embracing an open book, but remove the entire plant, stem, leaves and all tiny marks so the center is open negative space. Make the remaining moon and book shapes perfectly clean, smooth, flat, solid uniform muted sage #9bbda6. Remove all texture, grain, gradients, highlights, white edge flecks and stray pixels. Use fewer, thicker page shapes, only two page shapes per side of the open book. Keep the symbol bold and legible at favicon size. Centered square composition with clear space at the outer edges. Actual transparent background, preserve alpha. No text, no wordmark, no extra objects, no shadows, no mockup.
